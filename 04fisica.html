Lección 04 — Física, colisiones y plataformas

Activa Arcade Physics para tener gravedad, salto y colisiones automáticas.

📖 Ver teoría
Activar física en el config 
physics: {
  default: 'arcade',
  arcade: {
    gravity: { y: 400 }, // gravedad
    debug: false
  }
}
Objetos con física vs sin física 
// CON física (se mueve, cae):
jugador = this.physics.add
          .sprite(x, y, 'img');

// SIN física / estático (plataforma):
plats = this.physics.add.staticGroup();
plats.create(x, y, 'img');
Colisión entre objetos 
// Hace que A y B choquen:
this.physics.add.collider(A, B);

// Detectar overlap (recolección):
this.physics.add.overlap(
  A, B, callback
);
Saltar 
// Solo saltar si está en el suelo:
if (
  cursors.up.isDown &&
  jugador.body.touching.down
) {
  jugador.setVelocityY(-400);
  // Negativo = hacia arriba
}
