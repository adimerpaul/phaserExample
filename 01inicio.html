Lección 01 — ¿Qué es Phaser?

Framework JavaScript para crear juegos 2D en el navegador. Sin instalación: solo un <script>.

📖 Ver teoría (clic para abrir/cerrar)
¿Qué es Phaser? Framework gratuito para juegos 2D en el navegador. Usa WebGL para renderizar gráficos rápidos. Solo necesitas un <script> y ya funciona.
¿Qué juegos puedo hacer? Plataformas, puzzles, RPG 2D, shooters, top-down, endless runner… cualquier cosa en 2D. Para 3D se usa otra librería (Three.js).
