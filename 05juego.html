Lección 05 — Juego completo: Recolecta monedas

Un mini juego con jugador, monedas, enemigos, puntaje, game over y reinicio.

📖 Ver teoría — partes de un juego completo
Grupos de objetos 
// Crear un grupo:
monedas = this.physics.add.group();

// Agregar objetos al grupo:
monedas.create(x, y, 'img');

// Recorrer el grupo:
monedas.getChildren().forEach(m => {
  m.x = ...;
});
Overlap = recolección 
// Cuando jugador toca una moneda,
// llama a la función 'recolectar':
this.physics.add.overlap(
  jugador,
  monedas,
  recolectar
);

function recolectar(jugador, moneda) {
  moneda.destroy(); // quitar del juego
  puntos++;
}
Temporizador 
// Llamar función cada 2 segundos:
this.time.addEvent({
  delay: 2000,
  callback: spawnMoneda,
  callbackScope: this,
  loop: true
});
Game Over y reinicio 
// Detener física:
this.physics.pause();

// Mostrar texto game over:
this.add.text(x, y, 'GAME OVER', ...);

// Reiniciar la escena al hacer clic:
this.input.on('pointerdown', () => {
  this.scene.restart();
});
