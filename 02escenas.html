Lección 02 — Escenas y ciclo de vida

Una escena = una "pantalla" del juego. Menú, nivel 1, game over… cada una tiene su propio preload/create/update.

📖 Ver teoría
¿Qué es una escena? Como las pantallas de un juego: menú principal, nivel 1, nivel 2, game over… Cada escena es independiente y tiene su propio código.
Los 3 métodos 
preload() → carga imágenes/audio
          (se ejecuta 1 vez, antes de todo)

create()  → construye la escena
          (se ejecuta 1 vez al iniciar)

update()  → game loop
          (se ejecuta ~60 veces/segundo)
Cambiar de escena 
// Ir a otra escena:
this.scene.start('NombreEscena');

// Pausar la actual:
this.scene.pause();

// Reiniciar la actual:
this.scene.restart();
Crear escenas con clase 
class MiEscena extends Phaser.Scene {
  constructor() {
    super({ key: 'MiEscena' });
  }
  create() {
    this.add.text(10, 10, 'Hola');
  }
}

// En el config:
scene: [Escena1, Escena2]
