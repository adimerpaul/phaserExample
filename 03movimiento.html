Lección 03 — Movimiento del jugador

Captura teclas del teclado y mueve un personaje en update() cada frame.

📖 Ver teoría
Capturar teclas de flecha 
// En create():
cursors = this.input.keyboard
          .createCursorKeys();

// Teclas disponibles:
cursors.left.isDown
cursors.right.isDown
cursors.up.isDown
cursors.down.isDown
cursors.space.isDown
Mover en update() 
function update() {
  if (cursors.left.isDown) {
    jugador.x -= 4; // mover izquierda
  }
  if (cursors.right.isDown) {
    jugador.x += 4; // mover derecha
  }
  // x = horizontal, y = vertical
  // y crece hacia ABAJO (no arriba)
}
Limitar al área del canvas 
// Evitar que salga de pantalla:
jugador.x = Phaser.Math.Clamp(
  jugador.x,
  0,    // mínimo
  500   // máximo (ancho del canvas)
);
Teclas personalizadas 
// En create(), usar WASD:
const W = this.input.keyboard
          .addKey('W');
const A = this.input.keyboard
          .addKey('A');

// En update():
if (W.isDown) jugador.y -= 4;
if (A.isDown) jugador.x -= 4;
