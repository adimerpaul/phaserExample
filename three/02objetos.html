Lección 02 — Crear objetos 3D

Geometría + Material = Mesh. Esas son las 3 piezas de cualquier objeto 3D en Three.js.

📖 Ver teoría
Geometría + Material = Mesh 
// Geometría = la FORMA (vértices, caras)
const geo = new THREE.BoxGeometry(1,1,1);

// Material = la APARIENCIA (color, brillo)
const mat = new THREE.MeshBasicMaterial({
  color: 0x00ff00
});

// Mesh = unión de los dos
const objeto = new THREE.Mesh(geo, mat);
scene.add(objeto); // ← añadir a la escena
Figuras disponibles

PlaneGeometry(w, h)        // plano

Posición, rotación, escala 
// Posición (x, y, z)
objeto.position.x = 3;
objeto.position.set(1, 2, 3);

// Rotación en radianes
objeto.rotation.y = Math.PI / 4; // 45°

// Escala
objeto.scale.set(2, 1, 1); // doble ancho

// Math.PI = 180 grados en radianes

{ color: 'red' }

{ wireframe: true }   // solo líneas
