Lección 01 — Introducción a Three.js

Los 3 ingredientes básicos: Escena + Cámara + Renderer. Sin ellos no hay nada.

📖 Ver teoría
¿Qué es Three.js? Librería JavaScript para crear gráficos 3D en el navegador. Usa WebGL por debajo (que usa la GPU), pero con una API mucho más simple. Sin Three.js, WebGL puro es muy difícil.

Los 3 elementos base 
// 1. Escena — el "mundo"
const scene = new THREE.Scene();

// 2. Cámara — el "ojo"
const camera = new THREE.PerspectiveCamera(
  75,    // fov: campo de visión
  w / h, // aspect: proporción
  0.1,   // near: mínimo visible
  1000   // far: máximo visible
);

// 3. Renderer — el "pintor"
const renderer = new THREE.WebGLRenderer();
renderer.setSize(w, h);
document.body.appendChild(
  renderer.domElement // canvas
);
Loop de animación 
// requestAnimationFrame llama a
// 'animate' ~60 veces por segundo
function animate() {
  requestAnimationFrame(animate);

  // aquí rotas, mueves objetos...
  cubo.rotation.y += 0.01;

  // al final, renderizar
  renderer.render(scene, camera);
}
animate(); // arrancar
