Lección 03 — Cámaras, luces y materiales

MeshBasicMaterial ignora la luz. MeshStandardMaterial la necesita para verse bien.

📖 Ver teoría
Tipos de luz 
// Ilumina TODO por igual (sin sombras)
// Como la luz del cielo
new THREE.AmbientLight(color, intensidad)

// Como el sol: rayos paralelos
// Genera sombras
new THREE.DirectionalLight(color, int)

// Como una bombilla
// Irradia en todas direcciones
new THREE.PointLight(color, int, distancia)

// Como un foco/linterna
new THREE.SpotLight(color, int)
MeshBasicMaterial vs MeshStandardMaterial 
// Basic: NO reacciona a la luz
// Siempre se ve igual, plano
new THREE.MeshBasicMaterial({
  color: 0xff0000
})

// Standard: SÍ reacciona a la luz
// Necesita al menos una luz en escena
new THREE.MeshStandardMaterial({
  color: 0xff0000,
  roughness: 0.5, // 0=espejo 1=mate
  metalness: 0.3  // 0=plástico 1=metal
})
Sombras 
// 1. Activar en el renderer
renderer.shadowMap.enabled = true;

// 2. La luz proyecta sombra
luzDireccional.castShadow = true;

// 3. El objeto proyecta sombra
cubo.castShadow = true;

// 4. El suelo recibe la sombra
suelo.receiveShadow = true;

// Si falta alguno, las sombras no aparecen
